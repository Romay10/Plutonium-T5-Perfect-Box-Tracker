# Plutonium-T5-Perfect-Box-Tracker
BO1 Zombies / Plutonium T5 Perfect Box Patch with integrated Box Hits Tracker HUD.
Release description:
Initial public release of Plutonium T5 Perfect Box Tracker.

This release includes:

- Perfect Box / First Box logic for every BO1 Zombies map
- Integrated Box Hits Tracker HUD
- Total box hit tracking
- Good hit percentage tracking
- Individual good weapon percentage tracking
- Spam messages removed
- No external .exe required

Installation:

Place common_zombie_patch.ff in:

%localappdata%\Plutonium\storage\t5\zone

Make sure the file is named exactly:

common_zombie_patch.ff

Back up your original file before replacing it.
